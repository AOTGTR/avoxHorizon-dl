# avoxHorizon-dl

คู่มือภาษาไทยลง **Horizon** (Minecraft: Java Edition 26.3 ที่เขียนใหม่ด้วย Rust) ผ่านลันเชอร์ทางการ 8 ขั้น พร้อมรูปทุกขั้น

**เปิดคู่มือ:** https://aotgtr.github.io/avoxHorizon-dl/

- ตัวเกมและลันเชอร์เป็นของโปรเจกต์ [horizon-rust/horizon](https://github.com/horizon-rust/horizon) โหลดจากที่นั่นหรือ [playhorizon.dev](https://playhorizon.dev) เท่านั้น
- repo นี้มีแค่หน้าคู่มือ ไม่มีไฟล์เกม
- ต้องมีบัญชี Microsoft ที่ซื้อ Minecraft: Java Edition แล้ว
